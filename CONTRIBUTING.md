# Contributing

Bug reports and feature requests are very welcome: please [open an issue](https://github.com/mifsopo1/MifBlender/issues) with
your Blender version, your AI app, and the call and reply if you have them.

**This repository is generated.** Each release replaces its files from a private source tree, so a pull request merged here
would be overwritten by the next release. A pull request is still a good way to show a fix: it gets applied at the source
by hand, with credit, and the fix arrives in the next release. By opening one you agree that your change may be used under
the license of the part it touches.

The add-on is MIT licensed. The server's license lets you fork this repository only to propose changes back; see
`LICENSE.txt`.
